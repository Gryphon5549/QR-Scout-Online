Team 2549 • How it works

Use QR Scout in five quick steps.

Host the site on GitHub Pages, connect it to a Google Apps Script backend, and send each scouting entry directly to a Google Sheet.

1

Open the scouting form

Load the sample config or upload your own JSON. The app will build the form instantly in the browser with the fields your team needs.

2

Fill out the match

Enter match data, robot info, booleans, counters, dropdowns, and notes. The layout is built for fast in-match entry without slowing the team down.

3

Commit the entry

When you are ready, click Commit to review the form. From there you can generate a QR code or send the same record to the Google Sheet.

4

Generate the QR code

Use the QR code to save a portable version of the scouting data. This is helpful for backup, sharing, or recovering the entry later.

5

Sync to Google Sheets

Paste the Apps Script Web App URL and the shared Google Sheet link into the sync panel, then click Save Sheet sync. After that, select Sync to Sheet from the modal and the data is sent to the sheet.

How to set up the sync

  1. Host the website on GitHub Pages or run it locally with a web server.
  2. Create a Google Apps Script project and deploy it as a Web App.
  3. Set the deployment to “Anyone” so the browser can access it.
  4. Paste the deployed Apps Script URL and the shared Google Sheet link into the site.
  5. Save the sync settings and test by sending one scouting entry.

Helpful tips

  • Always open the site through a web URL like localhost or GitHub Pages instead of a file path.
  • Use a clear tab name like “Scouting” or “Sheet1” if your sheet has multiple tabs.
  • Keep your JSON field names consistent so the sheet rows stay easy to read and analyze.
  • Use the sample config first to test the flow before building a custom team form.
  • Save the sync values once so every future submission is one click away.
