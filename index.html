Team 2549 • Setup guide

How QR Scout works.

This system uses one clean setup: the website runs on GitHub Pages, the backend runs on Google Apps Script, and the data goes straight into a Google Sheet.

1

Open the live site

Host the website on GitHub Pages or run it on localhost. Do not open the project as a local file. Browsers do not allow the fetch needed for sync from a file:// page.

2

Deploy the backend

Create a Google Apps Script project and deploy it as a Web App. This is the only place that can write to the Google Sheet for you.

3

Paste the two links

Put in the deployed Apps Script URL and the shared Google Sheet link. If your sheet has multiple tabs, enter the tab name too.

4

Fill and commit

Use the scouting form to enter match data, then click Commit. From the review modal, choose Sync to Sheet to append the row to the spreadsheet.

5

Check the sheet

Open the Google Sheet and verify that the new row appears. If it does, the full flow is working and the setup is complete.

Exact setup checklist

  1. Push the website to GitHub and enable GitHub Pages.
  2. Open Google Apps Script and paste in the backend code.
  3. Deploy as a Web App with “Execute as: Me” and “Who has access: Anyone”.
  4. Copy the Web App URL that ends in /exec.
  5. Share the Google Sheet and copy its link.
  6. Paste both URLs into the site and save the sync settings.
  7. Test once with a real scouting entry.

Rules to remember

  • Use the deployed Apps Script URL, not the sheet URL.
  • Use the shared Google Sheet link, not the editor URL.
  • Never open the site from a file path while testing sync.
  • Keep the Apps Script set to Anyone so GitHub Pages can reach it.
  • If the browser says NetworkError, reload the live page and verify the URLs again.
