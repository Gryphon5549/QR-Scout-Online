Team 2549 • How it works

Build a scouting form in a few quick steps.

Use a JSON scouting configuration to define your fields, load it locally in the browser, and generate a QR code from the data you collect during competition.

1

Load your configuration

Choose a JSON file or use the sample scouting form to start with an example team layout. The app validates the structure and immediately builds your form in the browser.

2

Fill in the fields

Enter initials, match number, robot details, and any match metrics you need. Toggle booleans, adjust counters, set ranges, and use dropdowns for standard scouting options.

3

Commit the entry

When you are ready, click “Commit” to review your data. From the review modal, you can generate a QR code or send the same record to your sheet.

4

Generate or share

Use the QR image for quick sharing or save it as a PNG file. The generated code includes the same JSON data you entered, which makes it easy to scan and reuse later.

5

Sync to Google Sheet

Open the Google Sheet sync panel in the scouting page, paste your Google Apps Script web app URL, and click “Save Sheet sync.” After that, select “Sync to Sheet” from the commit modal and the app sends the row directly to the sheet.

How to set up sheet sync

  1. Create a Google Apps Script project tied to your sheet and deploy it as a web app.
  2. In the script, accept a JSON POST body and use the row data to append to the active sheet.
  3. Paste the deployed web app URL into the sync field on the scouting page.
  4. Click “Save Sheet sync,” then use the Commit modal to send the current scouting entry.
  5. Every synced row is appended in order, making it easy to track match data without manual entry.

Helpful tips

  • Keep field names consistent so your JSON stays easy to read and debug.
  • Use boolean and counter fields for fast pit-side collection during active matches.
  • Use the JSON manager to edit or download the current config without leaving the page.
  • Start with the sample form if you want a good baseline before creating your own team config.
  • For live testing, keep the Apps Script URL saved in the sync panel so one click is all it takes to send data.
