Millerbots • Setup guide

How the scouting flow works.

QR Scout is built around one simple idea: collect match data fast, keep it organized, and send the results into a clean Google Sheet workflow without slowing down the team.

1

Open the live site

Run the website through GitHub Pages or localhost. A real web URL is required so the browser can send scouting data to the backend.

2

Deploy the backend

Set up a Google Apps Script Web App and deploy it with access set to Anyone. This is the part that talks to Google Sheets.

3

Add the script link

Paste the deployed Apps Script URL into the app. If you want the data to land in a specific tab, add the tab name as well.

4

Fill and commit

Use the form to record match data, click Commit, then choose to sync the entry or generate a QR code for a backup.

5

Check the sheet

Open the target Google Sheet and verify the row appears. If it does, the whole Millerbots workflow is working as intended.

Setup checklist

  1. Host the website on GitHub Pages or localhost.
  2. Open Google Apps Script and paste in the backend code.
  3. Deploy the script as a Web App with “Execute as: Me” and “Who has access: Anyone”.
  4. Copy the URL that ends in /exec.
  5. Paste that URL into the site and save it.
  6. Test the sync by sending a real scouting entry.

Important reminders

  • Use the Apps Script URL, not the Google Sheet URL.
  • Do not open the site from a file path while testing.
  • Keep the backend deployment set to Anyone.
  • If a fetch request fails, reload the site from localhost or GitHub Pages and retry.
